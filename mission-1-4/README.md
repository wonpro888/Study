# 판다마켓 미션 1~4

ZIP을 풀고 `panda-market` 폴더를 VS Code로 열어 주세요. Node.js와 npm이 설치되어 있으면 첫 실행은 아래 한 줄이면 됩니다. 미션 4의 화면은 미리 빌드해 두었습니다.

```sh
npm start
```

브라우저에서 [판다마켓 열기](http://127.0.0.1:3000/)를 누르세요. 첫 화면의 **구경하러 가기**를 누르면 미션 4의 중고마켓이 열립니다. 첫 화면 오른쪽의 **로그인**을 누르면 미션 2의 로그인 화면으로 이동하고, 하단 링크로 회원가입 화면도 볼 수 있습니다. 서버를 종료할 때는 터미널에서 Ctrl+C를 누르세요.

## 공부할 때 열어 볼 파일

| 폴더 | 시작 파일 | 내용 |
| --- | --- | --- |
| `mission-1` | `index.html` | 첫 번째 랜딩 화면과 스타일 |
| `mission-2` | `index.html`, `login.html`, `signup.html` | 랜딩, 로그인, 회원가입 화면 |
| `mission-3` | `src/main.js`, `src/services/`, `src/models/` | JavaScript로 상품·게시글 데이터를 요청하고 모델로 다루는 예제 |
| `mission-4` | `src/App.js`, `src/pages/MarketPage/` | React 중고마켓, 베스트 상품, 검색·정렬·페이지 이동 |

원래 파일명, 폴더 안의 경로, 코드와 주석을 보존했습니다. 통합 실행에 추가한 파일은 최상위의 `start.cjs`, `package.json`과 이 안내서입니다. `mission-4/build`에는 미션 4 소스로 만든 실행용 화면이 있습니다.

미션 4의 상품 데이터는 원본에 지정된 강의용 외부 API에서 가져옵니다. 실제 상품을 보려면 해당 API에 접속할 수 있어야 합니다. 중고마켓 헤더의 로그인과 상품 등록 버튼은 미션 4 원본에서는 화면 요소로만 구현되어 있습니다. 계정 생성이나 상품 등록까지 구현된 버전은 아닙니다.

미션 3의 `src/main.js`는 기본 설정으로 외부 실습 서버에 상품과 게시글을 생성·수정·삭제합니다. 통합 실행은 이 예제를 호출하지 않습니다. 동작 흐름은 `main.js`와 두 서비스 파일을 함께 열어 확인할 수 있습니다.

## 미션 4를 수정한 뒤 화면 갱신하기

현재 ZIP의 미션 4 빌드 결과는 바로 열립니다. 나중에 React 소스를 수정할 때는 프로젝트 최상위에서 아래 명령을 순서대로 실행한 뒤 중고마켓 화면을 새로고침하세요. 첫 번째 명령은 빌드 도구를 설치할 때 한 번만 필요합니다.

```sh
npm --prefix mission-4 ci
npm run build
```

미션 2의 HTML·CSS는 저장 후 브라우저를 새로고침하면 바로 반영됩니다.
